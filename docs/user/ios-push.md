# iOS notifications and Live Activities

The iOS app can register directly with every connected NorthBridgeCode environment. Each environment owns its registrations and delivery, so removing one environment does not affect notifications from another.

Use **Settings → Agent Awareness** to enable or disable notifications and Live Activities on this device. If an environment operator has not configured APNs, ordinary local and remote NorthBridgeCode features continue to work; only that environment's iOS push delivery is unavailable.
